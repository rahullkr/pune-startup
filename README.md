# Pune Startup Arena

Job board and startup discovery platform for Pune. The stack is a Spring Boot API, a React/Vite frontend, a Python job scraper, PostgreSQL with PostGIS, Redis, and RabbitMQ.

## Repository layout

| Path | Contents |
| --- | --- |
| `backend/` | Spring Boot 3.5 / Java 21 API, Flyway migrations, integration tests |
| `frontend/` | React 19 / TypeScript / Vite 6 single-page app |
| `scraper/` | Python 3.12 scraper/worker that publishes discovered jobs to RabbitMQ |
| `ai/` | Placeholder package for future matching/parsing work |
| `.github/workflows/ci.yml` | Build and test pipeline for all three components |
| `docker-compose.yml`, `docker-compose.prod.yml` | Local services and production stack |
| `.env.example` | Template for all required environment variables |

## Prerequisites

- Docker with Compose
- Java 21 and Maven
- Node.js 22 and npm
- Python 3.12

## Local development

```powershell
Copy-Item .env.example .env
docker compose up -d
```

Start the API from `backend/` (Flyway applies migrations on startup):

```powershell
cd backend
mvn spring-boot:run
```

Start the frontend in a second terminal from `frontend/`:

```powershell
cd frontend
npm ci
npm run dev
```

Start the scraper manually from `scraper/` when needed:

```powershell
cd scraper
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m app.main
```

Use `python -m app.main`, not `python app/main.py`.

### Local endpoints

| Service | URL |
| --- | --- |
| Frontend | http://localhost:5173 |
| API base | http://localhost:8080/api/v1 |
| Health check | http://localhost:8080/actuator/health |
| RabbitMQ management | http://localhost:15672 |

The Vite dev server proxies `/api` to `http://localhost:8080`. Credentials for PostgreSQL, Redis, RabbitMQ, and the admin API key come from `.env`; never commit `.env`.

## API overview

The API exposes public endpoints for browsing jobs, companies, industries, skills, and map markers; authenticated candidate endpoints under `/api/v1/candidates/me` for profiles, saved jobs, followed companies, applications, job matches, and resumes; auth endpoints under `/api/v1/auth`; and admin endpoints under `/api/v1/admin` protected by `ADMIN_API_KEY`.

## Tests

```powershell
cd backend; mvn test
cd frontend; npm run typecheck; npm run build
cd scraper; python -m pytest -q
```

The same commands run in CI on pushes and pull requests to `main`.

## Free demo deployment

The included `render.yaml` and `frontend/public/_redirects` target a no-card demo stack:

| Layer | Service |
| --- | --- |
| Frontend | Cloudflare Pages |
| API | Render free Docker web service |
| Database | Neon Postgres with PostGIS |
| Cache | Upstash Redis |
| Queue | CloudAMQP free RabbitMQ |
| Resume storage | Cloudflare R2 |

Render free web services sleep after 15 minutes of inactivity and the workspace gets 750 free instance hours per month. Render does not offer free background workers, so the Python scraper is not part of this blueprint. Keep `INGESTION_SCHEDULER_ENABLED=false` until a worker is running.

### 1. Provision dependencies

- Neon: create a Postgres database, enable the `postgis` extension, and copy the direct connection string without `-pooler`; keep `sslmode=require` for Flyway.
- Upstash Redis: create a free database and copy the endpoint, port, and token from the TCP connection details.
- CloudAMQP: create a free Little Lemur RabbitMQ instance and copy the AMQP URL; use its host, user, password, and vhost with port `5671`.
- Cloudflare R2: create a bucket and a scoped API token; use `https://<account-id>.r2.cloudflarestorage.com` as the endpoint.

### 2. Deploy the API on Render

Create a new Render Blueprint and connect this repository; `render.yaml` defines `pune-startup-api` from `backend/Dockerfile` with `/actuator/health` as the health check. Fill the prompted values:

| Variable | Source |
| --- | --- |
| `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD` | Neon direct connection string and role |
| `REDIS_HOST`, `REDIS_PORT`, `SPRING_DATA_REDIS_PASSWORD` | Upstash endpoint, port, token |
| `RABBITMQ_HOST`, `RABBITMQ_USER`, `RABBITMQ_PASSWORD`, `SPRING_RABBITMQ_VIRTUALHOST` | CloudAMQP AMQP URL |
| `CORS_ALLOWED_ORIGINS` | Cloudflare Pages origin from step 3, no trailing path |
| `R2_ENDPOINT`, `R2_BUCKET_NAME`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` | Cloudflare R2 bucket and token |

`ADMIN_API_KEY` is generated by Render; read it from the service dashboard for `/api/v1/admin` calls. Redis and RabbitMQ use TLS in this blueprint. Free instances have 512 MB RAM, so the blueprint sets `JAVA_TOOL_OPTIONS=-Xmx384m`; increase the heap or move to a paid plan if the JVM needs more.

### 3. Deploy the frontend on Cloudflare Pages

Connect this repository and use these build settings:

| Setting | Value |
| --- | --- |
| Root directory | `frontend` |
| Build command | `npm ci && npm run build` |
| Output directory | `dist` |
| `NODE_VERSION` | `22` |
| `VITE_API_BASE_URL` | `https://<render-api-host>/api/v1` |

The committed `_redirects` file rewrites deep links to `index.html` so React Router refreshes work.

### 4. Verify

```powershell
Invoke-RestMethod "https://<render-api-host>/actuator/health"
Invoke-WebRequest "https://<pages-host>/" | Select-Object StatusCode
```

Open the frontend and confirm the job list loads; browser requests go directly to `VITE_API_BASE_URL`. Set `CORS_ALLOWED_ORIGINS` to the exact Pages origin and redeploy the API if the browser blocks requests.

### 5. Run the scraper separately

Run `python -m app.main` locally with `SCRAPER_REQUIRE_ENV=true` and the CloudAMQP TCP settings, or schedule it as a short-lived GitHub Actions job. The RabbitMQ consumer uses AMQP `5672`, so use a separate non-TLS CloudAMQP connection or add TLS support before running it permanently.

## Self-hosted production

Set the production environment variables, then from the repository root:

```powershell
docker compose -f docker-compose.prod.yml up -d --build
```

Rotate all placeholder secrets from `.env.example` before exposing the stack publicly.
